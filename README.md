# Whitethorn Morris website

This is a collection of html files together with javascript and css files that make up the static website for the Whitethorn Morris side.

The site was made using the [Modern Business](http://startbootstrap.com/template-overviews/modern-business/) template, which is a multipurpose, full website template for [Bootstrap](http://getbootstrap.com/) created by [Start Bootstrap](http://startbootstrap.com/).


## Status

* Home page - done
* About page - done
* Diary page - done
* Contact page - done
* Gallery page - done, more photos are added as they are received
    * Add new gallery pages for particular events or for each year (when we have enough photos)?
* Blog - done, but more posts can be added.
